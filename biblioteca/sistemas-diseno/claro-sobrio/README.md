# Sistema «claro-sobrio»

Claro, tranquilo y legible. Pensado para quien usa la aplicación todo el día.

## Reglas de uso
- **Fondo `#f6f7f9`, tarjetas blancas** con borde `linea` y sombra muy suave. Evita sombras fuertes y degradados.
- **Un acento (verde petróleo)** para la acción primaria, el enlace y el elemento activo. Todo lo demás es neutro. Los estados (éxito, aviso, error, info) siempre llevan texto o icono.
- **Texto** `#14202b` sobre blanco (contraste > 15:1). El texto atenuado `#5b6b7a` (≈ 5,3:1) solo para metadatos.
- **Tipografía:** Inter en todo; cuerpo 16 px, interlineado 1,55; cifras tabulares en tablas y totales; JetBrains Mono para códigos.
- **Formularios:** etiqueta arriba del campo, campo de 44 px de alto, error en rojo con icono y texto bajo el campo, ayuda en gris.
- **Tablas:** encabezado fijo, filas de 48 px, alineación numérica a la derecha, estado vacío con mensaje y acción.
- **Móvil:** una columna, objetivos de 44 px, acciones primarias abajo al alcance del pulgar.
- **Marca del cliente:** cuando llegue su identidad, solo cambian `acento`, `acentoSuave` y la tipografía de títulos; los neutros no.

## Fuentes
Google Fonts: Inter (400, 500, 600, 700) y JetBrains Mono (400, 500) con `display=swap`.
